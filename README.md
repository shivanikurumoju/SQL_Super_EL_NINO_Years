# SQL Super El Niño Years Analysis

## Project Overview

This project analyzes the Super El Niño Years dataset using PostgreSQL to explore climate patterns through SQL queries. The analysis focuses on filtering data, calculating summary statistics, grouping records, and extracting meaningful insights from historical El Niño events.

## Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT
- SUM
- AVG
- MIN
- MAX
- ROUND
- LIMIT

## Project Files

- `Full_Table.sql` – Main table creation and dataset.
- `Full_Table(Queries).sql` – All analysis queries.
- `Full_Table(Summary).sql` – Summary queries and key results.

- Data Retrieval
- Data Aggregation
- Filtering
